# CloudEdge-VLN: 基于端云协同双系统（System 1 & 2）的长程视觉语言导航框架

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![System 2: GPT-6 / Qwen](https://img.shields.io/badge/System%202-GPT--6%20%7C%20Qwen-blue)](https://github.com/)
[![System 1: Uni-NaVid](https://img.shields.io/badge/System%201-Uni--NaVid-green)](https://github.com/jzhzhang/Uni-NaVid)

本项目提出了一种**端云结合的双系统（System 1 + System 2）长程视觉语言导航（Long-Horizon VLN）框架**。通过将云端多模态大模型的复杂逻辑推理能力与端侧导航模型的实时动作生成能力相结合，有效解决了单一端侧模型在长程复杂指令下易迷失、缺乏全局规划与纠错能力的问题，同时保障了机器人底盘控制的低延迟实时性。

---

## 🧠 核心架构：快慢双系统端云协同

本框架采用认知科学中的“快慢思考（System 1 & System 2）”范式，将长程导航任务解耦至云端与端侧协同执行：

```text
                        [人类长程复杂自然语言指令]
                                    │
                                    ▼
┌───────────────────────────────────────────────────────────────────────┐
│ 云端大脑 System 2 (慢思考：GPT-6 / Qwen)                               │
│  • 长程任务拆解：将跨区域复杂长指令拆解为阶段性短程子任务队列            │
│  • 状态监控与纠错：基于回传关键帧判断子任务完成度、识别偏航并动态重规划   │
└───────────────────┬───────────────────────────────────────▲───────────┘
         下发当前阶段短程子指令                      回传稀疏关键帧与执行状态
                    ▼                                       │
┌───────────────────┴───────────────────────────────────────┴───────────┐
│ 端侧小脑 System 1 (快思考：Uni-NaVid)                                  │
│  • 实时短程推理：接收短程指令与连续视频流，在端侧高频输出离散控制动作     │
│  • 局部闭环执行：直接驱动机器人底盘完成局部导航、避障与目标接近          │
└───────────────────────────────────────────────────────────────────────┘
```

### 1. 云端大脑：System 2（长程规划与全局纠错）
* **支持模型**：支持灵活配置与切换 **GPT-6**、**Qwen（通义千问）** 等主流云端大模型/多模态大模型。
* **核心职责**：
  * **长程任务拆解（Task Decomposition）**：解析人类下发的跨房间、多阶段复杂自然语言指令，将其拆解为端侧模型易于执行的原子级短程导航子指令序列（Sub-instructions）。
  * **进度判断与动态纠错（Error Correction）**：低频接收端侧回传的稀疏视觉关键帧与历史轨迹状态，判断当前子任务是否达成；当检测到目标丢失、走错路口或陷入死胡同等异常状态时，触发反思机制并动态修正后续子指令。

### 2. 端侧小脑：System 1（实时短程导航推理）
* **基础模型**：基于 **Uni-NaVid** 部署于机器人端侧边缘计算平台（如 Jetson Orin NX 等）。
* **核心职责**：
  * **高频动作输出**：接收云端 System 2 下发的当前阶段短程子指令，结合本地连续第一视角 RGB 视频流，在端侧进行低延迟实时推理。
  * **局部闭环控制**：无需等待云端通信往返，独立完成当前子任务下的前进（Forward）、左转（Left）、右转（Right）、停止（Stop）等实时动作输出，保障机器人在动态环境中的响应速度与运动连续性。

## 🌟 核心亮点

* **长程导航与实时控制兼顾**：云端负责低频高维语义规划与全局纠错，端侧负责高频局部视觉导航，突破端侧算力对长上下文推理的限制，同时规避纯云端控制方案的网络延迟风险。
* **插件化云端基座支持**：提供统一的 System 2 接口封装，支持通过配置文件或环境变量一键切换 **GPT-6** 或 **Qwen** 系列模型。
* **闭环容错与鲁棒恢复**：引入基于视觉关键帧的状态反馈链路，使导航系统具备“发现偏航 -> 主动回退/重规划 -> 继续执行”的长程闭环容错能力。
